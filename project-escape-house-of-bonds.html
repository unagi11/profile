My Contribution

데이터 중심 스토리·다국어 시스템

  • 대사, 화자, 아이템, 정보, 튜토리얼, 도전과제를 TSV 데이터로 분리하고 공용 파서와 타입 안전 로더 구현
  • 대사 행에서 배경·초상화·BGM·화면 전환·아이템 변화·플래그·엔딩 크레딧을 함께 제어하는 효과 토큰 구조 설계
  • 한국어·영어·일본어 텍스트와 스프라이트 현지화, 에디터 ID 미리보기와 누락 검사 도구 구축
  • 플레이 기록과 현재 회차의 증거·선택을 조합해 A–E 다섯 엔딩으로 분기

방 탐색·아이템·퍼즐 구조

  • 오브젝트별 조건·결과를 직렬화한 상호작용 규칙과 역할별 특수 행동 핸들러로 방 진행 로직 분리
  • 아이템 획득·선택·조합·분해, 정보 수집, 오브젝트 상태 저장과 복귀 흐름 구현
  • 회차 seed에 따라 답과 순서가 달라지는 락픽, 체인 번호, 디지털 도어락 퍼즐 설계
  • 픽셀 퍼펙트 방 화면, Aseprite 시트 애니메이션, 조명·후처리·화면 전환 효과를 하나의 탐색 흐름으로 연결

Aseprite 기반 방탈출 제작 환경

  • Aseprite 원본을 CLI와 Lua 스크립트로 PNG 스프라이트 시트·JSON 메타데이터로 내보내고 Unity 에셋을 즉시 갱신
  • 레이어 구조·좌표·정렬 순서를 읽어 SpriteRenderer 계층을 자동 생성하고 기존 씬 오브젝트를 유지하며 갱신
  • Aseprite 태그를 반복·일회성 애니메이션과 프레임별 위치·재생 시간 데이터로 변환해 방 상태와 대사 연출에서 재생
  • 모든 방 원본을 한 번에 내보내고 현재 씬까지 갱신하는 일괄 리프레시 도구 구축

QA 전용 DSL과 자동 플레이

  • 한 줄에 한 행동을 기술하는 QA 전용 DSL로 터치, 대사 진행, 인벤토리 조합, 선택지, 퍼즐 결과를 스크립팅
  • 방 씬을 직접 조작하지 않고 타이틀의 새 게임부터 실제 가상 터치를 전달해 A–E 엔딩과 타이틀 복귀까지 검증
  • 정밀 조작이 필요한 미니게임만 실제 복귀 처리기에 성공 결과를 주입하고, 핵심 아이템·정보·잠금 상태는 런타임에서 단언
  • 0.25~20배속 실행, 명령별 제한시간, 자연스러운 마우스 이동, 중지·자동 종료와 Unity Profiler 기록 지원
  • 게임 화면 MP4 녹화와 15개 영문 트레일러 소스의 경로별 일괄 촬영·중단 지점 재개 기능 구현

Codex와 Unity CLI 기반 개발 환경

  • AGENT.md에 Unity 에셋·직렬화·코드 구조·검증 규칙을 명시해 Codex가 저장소 기준을 일관되게 따르도록 구성
  • Unity 프로젝트 작업과 시나리오 작성을 위한 저장소 전용 스킬을 제작해 반복 작업의 절차와 품질 기준을 재사용
  • Unity CLI와 Pipeline으로 열린 Unity Editor에 연결해 코드 수정 뒤 컴파일 상태, 콘솔 오류, 씬·프리팹 참조와 데이터 로딩 결과를 확인하는 검증 루프 구축
  • 기획과 구현 방향, 최종 판단은 직접 수행하고 Codex는 코드·데이터 조사, 반복 수정과 자동화 작업을 보조하는 협업 도구로 활용

플랫폼·저장·도전과제

  • Steam, Game Center·iCloud, Google Play Games, STOVE를 공통 플랫폼 서비스 인터페이스로 추상화
  • 로컬과 클라우드 저장의 시각을 비교해 최신 데이터를 선택하고, 연결 실패 시 로컬 저장으로 안전하게 전환
  • 20개 도전과제를 세 언어 데이터로 관리하고 플랫폼별 ID와 진행 상태 동기화

멀티 플랫폼 빌드·출시 자동화

  • Windows, Android, iOS, Steam 빌드를 공용 Unity 작업으로 묶고 태그 기반 버전·릴리스 흐름 구축
  • TestFlight·Google Play AAB 업로드, Steam 빌드·업데이트 배포와 플랫폼별 서명·스토어 설정 자동화
  • 빌드 결과물, 라이선스 고지, 스토어 캡슐·게임플레이 스크린샷 제작 도구까지 출시 파이프라인에 포함
